# Logourile din banda de pe pagina home

Banda de deasupra secțiunii „Ce spun clienții" caută fișierele de mai jos.
Cât timp un fișier lipsește, în locul lui rămâne numele brandului scris cu
text, ca banda să nu aibă goluri.

| Fișier               | Business          |
| -------------------- | ----------------- |
| `corks.png`          | Corks Cozy Bar    |
| `lee-coffee.png`     | Lee Coffee        |
| `renovision.png`     | Renovision Design |
| `rotary-cismigiu.png`| Rotary Cișmigiu   |
| `r-evolve-eq.png`    | R-Evolve EQ       |

PNG cu fundal transparent, înălțime în jur de 200px. Numele fișierului
contează — trebuie scris exact ca în tabel, cu literă mică.

Ca să adaugi un logo: deschizi acest folder pe GitHub → **Add file** →
**Upload files**.
