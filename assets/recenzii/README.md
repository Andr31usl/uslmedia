# Pozele autorilor de recenzii

Fiecare card din „Ce spun clienții" poate avea o poză în locul inițialelor.
Cât timp fișierul lipsește, cardul arată inițialele, deci nimic nu se strică.

| Fișier                    | Recenzie           |
| ------------------------- | ------------------ |
| `ruxandra-gabudean.png`   | Ruxandra Gabudean  |

Se decupează pătrat pe cap și umeri — cardul o taie rotund, la 34px. Urcă
poza întreagă aici și decupez eu.

Ca să adaugi o poză: deschizi acest folder pe GitHub → **Add file** →
**Upload files**.
